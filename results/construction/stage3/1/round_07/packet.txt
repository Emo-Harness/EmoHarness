## The two verification functions

Both are pure Python, read as text and run on the stage's JSON, so editing them
changes how a decision is made rather than what the model is asked. They issue
no model calls.

- `verification/cross_modal.py` exports `modalities_agree(record, hypotheses)
  -> bool`. It decides whether what was seen and what was heard point at the
  same label. Its answer becomes `modalities_agree` in the verification record,
  which the synthesis step is shown.
- `verification/alternative_hypotheses.py` exports `rank(record, hypotheses)
  -> list`. It orders the hypotheses; the output controller emits its labels
  from the front of that order, so this function decides the answer whenever
  two readings are close.

A replacement must pass a static check: no imports beyond `__future__` and
`typing`, no attribute access, no loop other than `for`, no comprehension other
than the ones already there, calls only to Python builtins from a closed list
(`len`, `sorted`, `sum`, `max`, `min`, `str`, `int`, `float`, `bool`, `list`,
`dict`, `set`, `abs`, `all`, `any`, `enumerate`, `range`, `round`) or to
functions you define in the same file, at most 20,000 bytes, and no branch keyed
on a particular label string. Keep the exported name and signature.

### prompts/verify.md
```
<!-- Rendered with str.format_map. Placeholders: {noun}, {label_set}, {audio_text}, {evidence_json}, {hypotheses_json}. -->
<!-- Optional placeholders this stage also accepts: {prompt}, {quantifier}. -->
<!-- A literal brace must be written twice: {{ becomes { and }} becomes }. -->

Re-examine an earlier reading of one video clip. Separate direct affective evidence from incidental content, then compare what was heard with what was seen.

WHAT WAS HEARD

{audio_text}

FULL EVIDENCE RECORD

{evidence_json}

EARLIER RANKING

{hypotheses_json}

The question asks for the {noun} displayed in the video.
The answer must be copied from this list, character for character: {label_set}

Work in this order:

1. Read the heard cues on their own. For sentiment, first perform an appraisal audit on the actual words: ask whether the speaker approves, praises, recommends, enjoys, appreciates, encourages, endorses, or favorably evaluates something, or instead criticizes, rejects, complains about, regrets, dismisses, threatens, insults, or unfavorably evaluates something. These explicit stance words support the corresponding positive or negative candidate even when spoken calmly. A factual mention of a person, event, plot, place, product, or topic is not automatically emotional. A generic instruction, question, advertisement setting, or energetic delivery without an appraisal is not by itself positive. A fragment must be judged only from the words that are present. Prosody can corroborate affect, but one generic pitch, loudness, speed, or pause tag is not decisive.
2. Read the seen cues on their own. Prioritize direct facial and bodily affect, expression changes, gaze, posture, gestures, and temporal change. Clothing, setting, ordinary sitting, generic mouth movement, and the number of scene descriptions are incidental. Do not make Neutral win merely because it can cite more incidental visual items, and do not make positive win merely because a person smiles while discussing a neutral topic.
3. Decide what each modality points to using the candidate labels exactly as written. For sentiment, classify the expressed stance and valence, not merely the apparent mood of the speaker. Explicit praise, approval, favorable evaluation, enjoyment, gratitude, encouragement, or recommendation remains positive even when understated or accompanied by a calm face. Explicit criticism, rejection, complaint, regret, dismissal, insult, threat, or unfavorable evaluation remains negative. Factual narration with no clear appraisal is neutral. For emotion, identify the affect visibly or vocally displayed.
4. Compare the readings. When they disagree, set `modalities_agree` to false and retain the meaningful alternatives. Resolve the disagreement by this priority: explicit evaluative wording, direct affective expression, specificity of the cue, persistence or temporal change, then cross-modal corroboration. Do not automatically select Neutral because the face is calm, and do not automatically follow the modality with more evidence items. Do not convert subject matter into sentiment: a serious topic is not automatically negative, and a positive-sounding topic is not automatically positive without an expressed stance.
5. Re-order and re-score the hypotheses after this second reading. A hypothesis must receive credit only from ids that genuinely support it. Neutral means no clear positive or negative stance, not merely factual wording, ordinary posture, or plentiful incidental items. Preserve a competing hypothesis when the evidence is genuinely ambiguous, but put the best-supported reading first.

Return a single JSON object and nothing else, with these keys:

- `modalities_agree`: `true` when the heard cues and the seen cues point to the same entry, `false` when they point to different entries.
- `hypotheses`: the same kind of list as the earlier ranking, with the keys `label`, `support`, `contradiction`, and `confidence`, re-ordered and re-scored after this second reading.

Rules:

- Keep every label exactly as it is written in the list above.
- Use only ids that appear in the record; drop any id you cannot find there.
- Do not invent a translation, event, facial expression, or emotional cue.
- When the two readings disagree, say so through `modalities_agree` and lower the confidences rather than hiding the conflict.
- Keep support and contradiction lists free of duplicate ids.
- Output JSON only: no prose before or after it, no code fence, no comments.
```

### verification/alternative_hypotheses.py
```
"""Alternative-hypothesis ranking (ADR-0005: no calibration, no label priors).

Stage 1 rule: order by stated confidence, then by how many supporting items exist
in the record, then by the order the hypotheses arrived in.

This file is loaded through the static allowlist in
``emoharness.harness.allowlist``: no imports beyond ``__future__`` and ``typing``,
no attribute access, no loops other than ``for``, and calls only to whitelisted
builtins or to functions defined here.
"""

from __future__ import annotations

from typing import Any


def rank(record: dict[str, Any], hypotheses: dict[str, Any]) -> list[dict[str, Any]]:
    """Hypotheses ordered from strongest to weakest."""
    rows = []
    index = 0
    for hypothesis in hypothesis_list(hypotheses):
        confidence = confidence_of(hypothesis)
        support = support_count(record, hypothesis)
        rows = rows + [(-confidence, -support, index, hypothesis)]
        index = index + 1
    ordered = sorted(rows)
    return [row[3] for row in ordered]


def confidence_of(hypothesis: dict[str, Any]) -> float:
    """The stated confidence, or 0.0 when there is none."""
    if 'confidence' in hypothesis:
        return float(hypothesis['confidence'])
    return 0.0


def support_count(record: dict[str, Any], hypothesis: dict[str, Any]) -> int:
    """How many supporting ids of a hypothesis exist in the record."""
    known = known_ids(record)
    count = 0
    for item_id in id_list(hypothesis, 'support'):
        if str(item_id) in known:
            count = count + 1
    return count


def known_ids(record: dict[str, Any]) -> set[str]:
    """Every citable id in the record."""
    return {str(item['id']) for item in item_list(record)}


def item_list(record: dict[str, Any]) -> list[Any]:
    """The record's citable items, or an empty list."""
    if 'items' in record:
        return list(record['items'])
    return []


def hypothesis_list(hypotheses: dict[str, Any]) -> list[Any]:
    """The hypothesis objects, or an empty list."""
    if 'hypotheses' in hypotheses:
        return list(hypotheses['hypotheses'])
    return []


def id_list(hypothesis: dict[str, Any], key: str) -> list[Any]:
    """One id list of a hypothesis, or an empty list."""
    if key in hypothesis:
        return list(hypothesis[key])
    return []
```

### verification/cross_modal.py
```
"""Cross-modal agreement flag (ADR-0005: one deterministic check, no resolution rule).

Stage 1 rule: the label best supported by seen items must equal the label best
supported by heard items. When one side supports nothing, there is nothing to
disagree with and the flag stays true.

This file is loaded through the static allowlist in
``emoharness.harness.allowlist``: no imports beyond ``__future__`` and ``typing``,
no attribute access, no loops other than ``for``, and calls only to whitelisted
builtins or to functions defined here.
"""

from __future__ import annotations

from typing import Any

SEEN_MODALITIES = ('visual',)
HEARD_MODALITIES = ('audio',)


def modalities_agree(record: dict[str, Any], hypotheses: dict[str, Any]) -> bool:
    """True when the seen cues and the heard cues favour the same label."""
    seen = top_label(record, hypotheses, SEEN_MODALITIES)
    heard = top_label(record, hypotheses, HEARD_MODALITIES)
    if seen == '' or heard == '':
        return True
    return seen == heard


def top_label(
    record: dict[str, Any],
    hypotheses: dict[str, Any],
    modalities: tuple[str, ...],
) -> str:
    """The label with the most supporting items in ``modalities``; '' when none."""
    rows = []
    index = 0
    for hypothesis in hypothesis_list(hypotheses):
        count = support_count(record, hypothesis, modalities)
        rows = rows + [(count, -index, str(hypothesis['label']))]
        index = index + 1
    ordered = sorted(rows, reverse=True)
    if len(ordered) == 0:
        return ''
    if ordered[0][0] == 0:
        return ''
    return str(ordered[0][2])


def support_count(
    record: dict[str, Any],
    hypothesis: dict[str, Any],
    modalities: tuple[str, ...],
) -> int:
    """How many of a hypothesis' supporting ids exist and sit in ``modalities``."""
    count = 0
    for item_id in id_list(hypothesis, 'support'):
        if modality_of(record, str(item_id)) in modalities:
            count = count + 1
    return count


def modality_of(record: dict[str, Any], item_id: str) -> str:
    """The modality of one evidence item, or '' when the id is unknown."""
    for item in item_list(record):
        if str(item['id']) == item_id:
            return str(item['modality'])
    return ''


def item_list(record: dict[str, Any]) -> list[Any]:
    """The record's citable items, or an empty list."""
    if 'items' in record:
        return list(record['items'])
    return []


def hypothesis_list(hypotheses: dict[str, Any]) -> list[Any]:
    """The hypothesis objects, or an empty list."""
    if 'hypotheses' in hypotheses:
        return list(hypotheses['hypotheses'])
    return []


def id_list(hypothesis: dict[str, Any], key: str) -> list[Any]:
    """One id list of a hypothesis, or an empty list."""
    if key in hypothesis:
        return list(hypothesis[key])
    return []
```

Where the improvement comes from

L0 · Direct

Student answers the official question from visual/video input in one call. No added audio text.

L1 · Fixed tools

Same direct task, with Whisper transcript and openSMILE audio features added as text. One student call.

L3 · Scaffold

Visual evidence → hypotheses → verification → synthesis. Code validates evidence and selects the final label. About four calls.

L5 · Frozen bundle

The same scaffold with Builder-selected changes. No Builder runs during this evaluation.

Added perception information helps all four students in this evaluation. The additional multi-step scaffold gain is larger for Qwen3.5 and Gemma. Builder changes show small, mixed effects, with no clear improvement at the conventional 5% level in the reported comparisons.

How the harness works

One student handles all four reasoning calls. Fixed perception tools provide observations; code validates evidence and controls the final labels. The offline Builder loop below produces the frozen bundle used at inference time.

Quality and budget

Inference uses student tokens on every example. Construction spends an additional API budget once, before the bundle is frozen. Read these two budgets separately.

Fixed tools add 1.5–1.9% student tokens for +4.65 to +10.96 points. Their preprocessing still has a cost. The scaffold then uses 2.14–2.56× the L1 tokens; its paired gain ranges from +0.37 to +4.48 points. The L5 change over L3 is small and mixed.

What changes on a real clip

Five clips from the evaluation set with the answers all four students actually produced, at direct answering, at the scaffold, and with the frozen bundle. Direct answering sees only the picture; the scaffold also receives the fixed Whisper transcript and openSMILE cues and must cite them by ID. Items where the harness helps and items where it hurts are both shown, for every model.

These five clips illustrate mechanisms; they are not a random sample and quoting them estimates no effect. Item counts over all 1,000 examples, on Qwen3-VL-8B: added perception information (L0 → L1) fixed 203 items and broke 83; the extra scaffold on top of it (L1 → L3) fixed 129 and broke 126, a near-wash consistent with its small overall gain; the frozen bundle (L3 → L5) fixed 10 and broke 4. The last clip is worth attention: three of four students answered it correctly without the harness, and the harness moved all four to the same wrong label, which points at the shared prompt rather than at any one model. Excerpts are shortened; bracketed IDs such as [a1] are the evidence references the harness requires. Reference labels come from MME-Emotion. Multi-label tasks use partial credit, so a check mark here means the item scored at least half credit.

How to read these results

Development evaluation, not a fresh held-out test. All rows use the same 1,000 examples, 125 per task. This subset has been inspected repeatedly. The reserved 129-item D_ext-test was not evaluated.

Uncertainty: task-stratified paired bootstrap with 10,000 resamples, pairing examples by ID. Intervals describe item-level uncertainty under this resampling scheme; they do not capture all source dependence, inference variation or adaptive model selection. Reported p-values are unadjusted for multiple comparisons.

Input scope: fixed ffmpeg / Whisper large-v3 / openSMILE preprocessing, without Omni analysis. Gemma’s native audio channel is not used in this main comparison. The single-call versus scaffold comparison also changes call budget and input organization; it is not an equal-compute architecture-only ablation.

Model scope: Qwen3-VL-8B-Instruct, Qwen3-VL-4B-Instruct, Qwen3.5-4B and Gemma-4-E4B-it. E4B denotes effective parameters, not an equal-total-parameter 4B control. Thinking was disabled for the new models. Environment and cache compatibility issues were corrected before the successful evaluations; failed attempts were retained separately.

Historical context: v1 with Omni scored 41.3% for the scaffold and 41.5% after Builder changes, versus 29.2% direct. Those are historical results, not this batch’s scores. Read the original page and examples →
